# Inventory Management System

Java application developed to manage inventory and simulate purchases in a store.

The project allows users to add, remove, search, and update products in the inventory, as well as add and remove products from a shopping cart, calculate the total purchase amount, and make payments using card or Pix.

### Features

* Product inventory management
* Adding and removing products
* Quantity and price updates
* Product search and listing
* Shopping cart management
* Inventory quantity control
* Purchase total calculation
* Card and Pix payment options
* Custom exception handling

### Applied Concepts

The project was developed using **Object-Oriented Programming (OOP)** concepts and **SOLID principles**, aiming to improve code organization, maintainability, and flexibility.

The project also applies:

* Generics
* Interfaces
* Encapsulation
* Inheritance and Polymorphism
* Custom Exceptions
* Separation of Responsibilities
* SOLID Principles

### Technologies

* Java
* Object-Oriented Programming
* SOLID
* Generics
* Interfaces
* Custom Exceptions

### Structure

The project is organized into different packages:

* `app` — main application class
* `model` — model classes such as Product, Inventory, and Shopping Cart
* `gerenciador` — inventory and shopping cart management
* `interfaces` — interfaces used by the system
* `pagamentos` — payment methods
* `excessoes` — custom exceptions
