# Sistema de Gerenciamento de Estoque

Sistema desenvolvido em Java para gerenciamento de estoque e simulação de compras em uma loja.

O projeto permite cadastrar, remover, buscar e atualizar produtos no estoque, além de adicionar e remover produtos de um carrinho de compras, calcular o valor total e realizar pagamentos por cartão ou Pix.

### Funcionalidades

* Gerenciamento de produtos no estoque
* Adição e remoção de produtos
* Atualização de quantidade e preço
* Busca e listagem de produtos
* Gerenciamento do carrinho de compras
* Controle da quantidade disponível em estoque
* Cálculo do valor total da compra
* Pagamento por cartão ou Pix
* Tratamento de exceções personalizadas

### Conceitos Aplicados

O projeto foi desenvolvido aplicando conceitos de **Programação Orientada a Objetos (POO)** e os princípios **SOLID**, buscando melhorar a organização, manutenção e flexibilidade do código.

Também foram utilizados:

* Generics
* Interfaces
* Encapsulamento
* Herança e Polimorfismo
* Exceções personalizadas
* Separação de responsabilidades
* Princípios SOLID

### Tecnologias

* Java
* Programação Orientada a Objetos
* SOLID
* Generics
* Interfaces
* Exceções personalizadas

### Estrutura

O projeto é organizado em diferentes pacotes:

* `app` — classe principal da aplicação
* `model` — classes de modelo, como Produto, Estoque e Carrinho
* `gerenciador` — gerenciamento do estoque e carrinho
* `interfaces` — interfaces utilizadas pelo sistema
* `pagamentos` — formas de pagamento
* `excessoes` — exceções personalizadas
